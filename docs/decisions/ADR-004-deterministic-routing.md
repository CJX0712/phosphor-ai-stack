# ADR-004：确定性可判定的问题不交给模型

作者：晨星 · 状态：已接受

## 背景

小参数模型在算术与单位换算上不可靠：实测 0.5B 模型会把 `12*(3+4)` 算成 72，而且失败是间歇性的，难以回归。

## 决策

在问题进入模型之前做**确定性前置路由**：

* 正则从整句中抽出连续片段（整句 `ast.parse` 必然语法错误），逐个校验并试算；
* 命中即调用 `calculator`，把结果作为 Observation 注入上下文；
* 模型只需复述已算好的数值，不需要重算。

同时把"确定性结果优先于抽取式结果"写进阅读器：存在 calculator 观测时直接返回该值。

## 细节约束

* 归一化表必须包含全角数字 U+FF10–FF19，否则 `１２×（３＋４）` 失败；
* 尾部裁剪字符集**绝不能包含运算符字符**（`+ - * /`），否则会切坏合法表达式；
* `ZeroDivisionError` / `OverflowError` 一并归一为 `ToolError`，不允许穿透。

## 后果

黄金集里 `12*(3+4) 等于多少？` 这条用例在纯默认配置下稳定返回 84；运行时不变量里也有一条专门守它。
