# ADR-003：融合用 RRF，重排默认词法，扩展只喂稀疏分支

作者：晨星 · 状态：已接受

## 背景

稠密余弦（0–1）与 BM25（0–几十）量纲不同，做分数归一化会让一路在另一路分布尾部被淹没。跨语言查询在稀疏分支上天然零交集。

## 决策

1. **融合用 RRF**：`score(d) = Σ_branch weight / (k + rank)`，k=60。排名融合与分值无关，因此稠密后端从哈希投影换成真正句向量时融合行为保持一致。
2. **重排默认词法**：IDF 加权重合度 + 完整短语命中 1.35 倍加成；安装 fastembed 后自动切交叉编码器，下载失败静默回退。
3. **双语扩展只作用于稀疏分支**：把"检索/嵌入/重排"等概念映射到对方语言，但**不喂给稠密分支** —— 否则两路结果趋同，融合带来的互补性被抵消。

## 后果

* 跨语言黄金用例（英文问题 -> 中文段落）默认配置下即可通过；
* 重排在离线机器上也参与了排序，因此重排路径是"被持续验证"的，而不是只在有模型时才执行；
* 代价：RRF 丢掉了分支内部的分数间距信息，对"两路都很确信"的候缺少额外加权。
