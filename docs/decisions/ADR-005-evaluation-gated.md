# ADR-005：评估永远在新管道上跑，门限贴着基线，契约从活代码导出

作者：晨星 · 状态：已接受

## 背景

三个独立的"自我欺骗"来源：

1. 评估复用运行期已写入数据的单例管道 -> 文档重复 -> 召回随机漂移；
2. 门限拍脑袋设定 -> 要么真回归不挂，要么浮点抖动天天挂；
3. 手写文档与实现漂移。

## 决策

1. **评估在全新管道上跑**：`run_evaluation(factory)` 接受一个工厂，每次调用先 `build_pipeline()` 再摄入黄金语料。
2. **门限贴着实测基线**：基线 1.000 -> 门限 0.85；基线数值同步写进 `docs/SPEC.md`，可追溯。
3. **契约从活代码导出**：`create_app().openapi()` 直接 dump 成 `docs/openapi.yaml`。
4. **聚合口径写清楚**：工具路由用例（设计上零证据）从检索聚合中剔除并单独计数；接地聚合排除零证据用例。

## 后果

* 评估数字可复现（同配置两次运行结果逐位一致，由 `determinism` 阶段守护）；
* 真回归必挂，抖动不挂；
* 文档与实现不会漂移，因为文档是导出的。
